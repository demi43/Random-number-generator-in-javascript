# Random-number-generator-in-javascript


This is a simple web-based **Random Number Generator** that simulates rolling three dice. Built using **HTML**, **CSS**, and **JavaScript**, it's a fun and interactive way to explore randomness and DOM manipulation.

---

## 🚀 Features

- Click the **Roll** button to generate 3 random numbers
- Numbers range from **1 to 6** (just like a standard die)
- Updates the values dynamically using JavaScript
- Clean, minimalist design — easy to read and use

---

## 🛠️ Technologies Used

- **HTML5** – structure and layout  
- **CSS3** – styling and spacing  
- **JavaScript** – logic for random number generation and DOM updates

---



## 💡 How It Works

- Uses `Math.random()` to generate numbers between 1 and 6
- Uses `Math.floor()` to ensure whole numbers
- Updates `<label>` elements with the new values every time you click **Roll**
